Other apps

Python, Node.js, curl

These ignore the Windows proxy and certificate store. In PowerShell:

$env:HTTPS_PROXY = "http://127.0.0.1:{{.ProxyPort}}"
$env:HTTP_PROXY = "http://127.0.0.1:{{.ProxyPort}}"
$env:REQUESTS_CA_BUNDLE = "{{.PEM}}"
$env:SSL_CERT_FILE = "{{.PEM}}"
$env:NODE_EXTRA_CA_CERTS = "{{.PEM}}"

Windows curl: curl -x http://127.0.0.1:{{.ProxyPort}} --ssl-no-revoke https://example.com

Firefox

Firefox normally trusts the Windows store. If not: Settings → Privacy & Security → View Certificates → Authorities → Import the .pem.

{{range .LAN}}

iPhone / iPad

Download it in Safari, then Settings → General → VPN & Device Management → install the profile, then Settings → General → About → Certificate Trust Settings → turn on "Sift CA".

Android

Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Chrome and the browser then work. Most Android apps only trust built-in certificates, so their HTTPS stays encrypted; Sift detects that and lets them through so they keep working.
